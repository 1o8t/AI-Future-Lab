# Demonstration Status

The code in this repository is designed as small educational starter examples.

## Environment Limitations

The engine editors and compilers are not available in the environment that generated this package, so the projects were not executed here.

## Intended Compatibility

- Godot: Godot 4.x
- Unity: Unity 6 or a recent compatible version
- Unreal: Unreal Engine 5.x C++ project

## Before Publishing a Release

Open each demonstration in the matching engine, compile or run it, and record:

- Engine version
- Operating system
- Result
- Screenshot
- Any required fix

Do not describe the full AI Future Lab platform as completed software. The current public project is an architecture, documentation, and visualization-demonstration project.
