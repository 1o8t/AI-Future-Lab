# مكتبة مسارات العمل — صفحة الوصول العربية

الشرح العربي الكامل لجميع مسارات AI Future Lab موجود هنا:

## [فتح مكتبة مسارات العمل العربية الكاملة](05-workflow-library.md)

تتضمن الصفحة:

- صور مسارات العمل الأحد عشر
- رابط Whimsical لكل مخطط
- الهدف من كل مسار
- المدخلات والخطوات والمخرجات
- الأخطاء المحتملة
- نقاط المراجعة والاعتماد البشري
- توضيح ما هو حالي وما هو مقترح للمستقبل

> المخططات تمثل هندسة مقترحة للنظام، ولا تعني أن جميع الخدمات الموضحة تعمل حاليًا.

المسار العام للمشروع:

```text
فكرة الإنسان
→ فهم AI والتوضيح
→ موجز مدينة معتمد
→ التخطيط الحضري
→ التوأم الرقمي
→ العرض والمحاكاة
→ النتائج القابلة للتفسير
→ المراجعة البشرية
```
