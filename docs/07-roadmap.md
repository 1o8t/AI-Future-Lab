# 07 — Roadmap

This roadmap describes a possible future development path. It is not a claim that these phases are already implemented.

## Phase 0 — Public Concept

- Complete project description
- Publish architecture
- Publish workflows
- Create project identity
- Gather feedback
- Protect private personal information

## Phase 1 — Planning Prototype

- Text input
- Structured city brief
- Clarification flow
- Simple AI planning response
- Saved projects
- Basic explainability

## Phase 2 — Interactive Map

- Site selection
- Map layers
- District polygons
- Road lines
- Service points
- Plan editing
- GeoJSON export

## Phase 3 — Planning Intelligence

- Candidate-plan generation
- Constraint validation
- Land-use balance
- Service accessibility
- Mobility analysis
- Sustainability indicators
- Plan comparison

## Phase 4 — Digital Twin

- Versioned city-object model
- Spatial relationships
- Scenario state
- Metrics history
- Decision traceability
- Revision comparison

## Phase 5 — Scenario Lab

- Population-growth scenarios
- Traffic-demand scenarios
- Service-demand scenarios
- Climate and resilience scenarios
- Utility-capacity scenarios
- Side-by-side results

## Phase 6 — Professional Reporting

- Executive dashboard
- Planning report
- Risk report
- Assumption register
- Decision evidence
- Export tools

## Phase 7 — Collaboration

- Team projects
- Comments
- Approval workflow
- Role-based access
- Planner review
- Public consultation mode

## Phase 8 — Production Readiness

- Security review
- Privacy controls
- Monitoring
- Backup
- Recovery
- Performance testing
- Controlled deployment
