# GitHub Publishing Guide

## Repository Name

`ai-future-lab`

## Description

`AI-powered urban-planning concept that transforms human ideas into structured, explainable and testable city plans.`

## Upload Through the GitHub Website

1. Sign in to GitHub.
2. Create a new public repository named `ai-future-lab`.
3. Do not initialize it with another README because this package already includes one.
4. Extract the ZIP package.
5. Open the new repository.
6. Choose **Add file → Upload files**.
7. Drag all files and folders from inside `AI_Future_Lab_Multi_Engine_Repo`.
8. Commit with the message:

   `Publish AI Future Lab architecture and engine demonstrations`
