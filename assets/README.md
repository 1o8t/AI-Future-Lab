# Workflow Assets | ملفات مسارات العمل

**English | العربية**

The `assets` folder is intentionally simple. It contains only the exported workflow images used to explain AI Future Lab.

مجلد `assets` بسيط ومخصص فقط لصور مسارات العمل التي تشرح مشروع AI Future Lab.

## Folder Structure | هيكل المجلد

```text
assets/
├── README.md
└── workflows/
    ├── README.md
    ├── 01-master-overview.png
    ├── 02-human-input-ai-understanding.png
    ├── 03-ai-core-architecture.png
    ├── 04-urban-planning-digital-twin.png
    ├── 05-city-generation-simulation.png
    ├── 06-results-explainability.png
    ├── 07-errors-recovery.png
    ├── 08-security-apis-monitoring.png
    ├── 09-learning-optimization.png
    ├── 10-deployment-operations.png
    └── 11-final-integrated-architecture.png
```

## Upload Rules | قواعد الرفع

- Upload workflow images only inside `assets/workflows/`.
- Use PNG format with readable text.
- Keep the complete workflow visible without cropped boxes or connectors.
- Remove private emails, account details, notifications, and private links.
- Use the exact approved filenames shown above.

- ارفع صور الـWorkflows فقط داخل `assets/workflows/`.
- استخدم صيغة PNG وتأكد أن الكتابة واضحة.
- يجب أن تظهر جميع المربعات والخطوط بدون قص.
- احذف البريد الخاص وبيانات الحساب والإشعارات والروابط الخاصة.
- استخدم أسماء الملفات المحددة أعلاه تمامًا.

No branding, diagrams, screenshots, or social-media folders are currently required.

لا توجد حاجة حاليًا لمجلدات الشعارات أو المخططات الإضافية أو لقطات الشاشة أو صور التواصل الاجتماعي.
