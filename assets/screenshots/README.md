# Project Screenshots | لقطات شاشة المشروع

Use this folder for safe screenshots of the GitHub page, future prototypes, dashboards, maps, and tested visual demonstrations.

استخدم هذا المجلد للقطات الشاشة الآمنة لصفحة GitHub والنماذج المستقبلية ولوحات المعلومات والخرائط والعروض التي تم اختبارها.

## Rules | القواعد

- Crop browser tabs and notifications.
- Remove private emails, usernames, school information, and account details.
- Do not label a concept image as a working application.
- Add the date and tested version when showing real software.

- احذف علامات تبويب المتصفح والإشعارات.
- أخفِ البريد الخاص وبيانات المدرسة والحسابات.
- لا تصف صورة تصورية بأنها تطبيق يعمل.
- أضف التاريخ والإصدار عند عرض برنامج حقيقي تم اختباره.
