# Unity City Generator Demo

## Target

Unity 6 or a recent Unity version that supports standard MonoBehaviour scripting.

## Setup

1. Create a new 3D Unity project.
2. Copy the `Assets` folder from this demo into the project.
3. Create an empty GameObject.
4. Name it `AI Future Lab City Generator`.
5. Add the `CityGenerator` component.
6. Press **Play**.

## Output

The script creates:

- A ground surface
- Road strips
- Procedural building blocks
- A camera when none exists
- A directional light when none exists

## Purpose

This is a small visualization demonstration only. It does not contain the complete AI planning platform.
