# Godot City Generator Demo

## Target

Godot 4.x.

## Run

1. Open Godot.
2. Import this folder by selecting `project.godot`.
3. Open the project.
4. Press **F6** or **F5**.

The scene generates a simple city using `MeshInstance3D` and `BoxMesh`.

## Controls

The demo has no player controls. Change `grid_size`, `spacing`, and `seed_value` from the Inspector after selecting the root node.

## Purpose

This is a procedural visualization demonstration only. It does not include the AI planning system.
